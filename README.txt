MELE FASHION CHATBOT - TERMUX

1. Extract this ZIP in your phone.
2. In Termux, go to the extracted folder.
3. Run:
   python -m http.server 9090 --bind 127.0.0.1
4. Open your phone browser and visit:
   http://127.0.0.1:9090

This first version has 20 design choices and 10 sample photos.
Design names 1-10 are editable in index.html if you want to match each photo
to the exact design name.
